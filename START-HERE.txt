YOUTUBE ALERTS BOT — QUICK START

1. Read README.md to create a Discord bot and YouTube Data API key.
2. Copy .env.example to .env and enter your two private keys.
3. Open a terminal in this folder:
   python -m pip install -r requirements.txt
   python bot.py
4. In Discord:
   /youtube add youtube:@YourChannel destination:#youtube-alerts
5. Test your destination:
   /youtube test destination:#youtube-alerts

For Render:
Upload this folder's CONTENTS to the root of a GitHub repository.
Create a new Render Blueprint using render.yaml.
It uses a paid background worker with a persistent disk.
Set the two private keys in Render when prompted.
See README.md for full manual settings.

Do not upload your real .env or data folder to GitHub.
No website, domain, callback URL, or Lavalink is needed.
